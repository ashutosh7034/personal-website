## 🎯 Design Philosophy & "Anti-AI" Aesthetic

This portfolio is deliberately designed to feel personal, technical, and grounded:

- **Carbon & Slate Palette:** Deep background surfaces (`#0A0B0D` / `#121417`) paired with a purposeful Solar Rust accent (`#F97316`) and muted slate borders (`#262A33`).
- **Zero AI Cliches:** No generic glowing neon purple orbs, no floating 3D spheres, no fabricated metric bars, and no stock testimonials.
- **Editorial Typography:** High-contrast hierarchy combining `Plus Jakarta Sans` for display headers, `Inter` for dense technical prose, and `JetBrains Mono` for metadata and architecture pipelines.
- **Mobile-First & Touch-Native:** 100% responsive across viewports from 320px mobile screens to 1920px 4K displays with dedicated hamburger drawer navigation and tap-first interactions.

## 🛠️ Getting Started (Local Development)

### 1. Prerequisites
- **Node.js**: `v18.17.0` or later
- **npm** / **yarn** / **pnpm**

### 2. Clone the Repository
```bash
git clone https://github.com/ashutosh7034/portfolio.git
cd portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

Edit `.env.local` if you wish to configure a custom Resend API key:
```env
RESEND_API_KEY=re_your_api_key_here
CONTACT_EMAIL=ashutosh3276s16@gmail.com
CONTACT_FROM_EMAIL=onboarding@resend.dev
```
*(Note: The contact form includes an automatic fallback relay, so messages will arrive even before configuring Resend).*

### 5. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 6. Create a Production Build
```bash
npm run build
npm run start
```

## 🚀 Deployment Guide

### Option 1: Deploy to Vercel (Recommended)

1. Push your code to your GitHub repository (see [GitHub Setup](#-uploading-to-github)).
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New..."** → **"Project"**.
4. Import your `portfolio` repository.
5. In **Environment Variables**, add:
   - `CONTACT_EMAIL`: `ashutosh3276s16@gmail.com`
   - `RESEND_API_KEY`: *(Optional: Your Resend API key)*
6. Click **Deploy**. Vercel will automatically build and assign a global CDN URL (e.g. `ashutosh-pandey.vercel.app`).

---

### Option 2: Deploy to Netlify

1. Push your code to GitHub.
2. Go to [netlify.com](https://netlify.com) and import the repository.
3. Set the build settings:
   - **Build command:** `npm run build`
   - **Publish directory:** `.next`
4. Add environment variables in Site settings → Environment variables.
5. Click **Deploy Site**.
